Glyphs for the town names, in MapLibre's PBF format: Noto Sans Regular and Medium, code points
0–511 (Latin-1 and Latin Extended-A). Taken from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) and served with the
site, so the map does not depend on a font host. Licensed under the SIL Open Font License
(`OFL.txt`).
